## 只学差异（Java → Python）

| 主题 | 和 Java 的关键区别 | 优先级 |
|---|---|---|
| 类型标注 | 运行时不强制，靠工具检查；`int \| None` 而不是 `Integer` | ★★★ |
| Pydantic | 类似 DTO + Bean Validation 合体，校验发生在构造时 | ★★★ |
| async/await | 单线程事件循环；`async def` 里**不能**调阻塞库 | ★★★ |
| 依赖注入 | `Depends()` 是函数调用，不是容器扫描 | ★★★ |
| 装饰器 | 类似注解，但能包住函数本身 | ★★☆ |
| 异常 | `try/except/else/finally`，异常就是控制流的一部分 | ★★☆ |
| 上下文管理器 | `with` ≈ try-with-resources | ★★☆ |
| 列表/字典推导 | 替代大量 for + add | ★★☆ |
| 虚拟环境 / uv | 类似 Maven，但环境和依赖都按项目隔离 | ★★★ |

**可以跳过**：基础循环、基础数据结构、面向对象入门、GIL 原理。
